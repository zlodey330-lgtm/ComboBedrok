# Bedrock Combo (Fabric 1.20.1)

Комба как в Minecraft Bedrock / PE. Бьёшь моба или игрока, и он подлетает вверх. Каждый следующий удар снова задаёт ему скорость вверх, поэтому цель держится в воздухе, пока ты попадаешь. Промахнулся или перестал бить, и цель падает.

## Сборка
Нужна JDK 17+.

    Windows:      gradlew.bat build
    Linux / Mac:  ./gradlew build

Готовый мод: `build/libs/bedrock-combo-1.0.0.jar` (не бери `-sources`).
Если Java не хочется ставить, залей папку в репозиторий на GitHub. Workflow `.github/workflows/build.yml` соберёт jar сам (вкладка Actions → Artifacts).

## Установка
Fabric Loader для 1.20.1, Fabric API и `bedrock-combo-1.0.0.jar` в `mods`.
- Одиночный мир: мод нужен только тебе.
- Открытый для друзей мир (LAN): мод нужен только хосту.
- Сервер: ставь на сервер. Клиентам мод не обязателен, но с ним индикатор перезарядки не мешает.

## Как это работает
Мод перехватывает отбрасывание от ближнего удара игрока:
- Удар по цели на земле даёт скорость вверх `launchVelocity`.
- Удар по цели в воздухе даёт скорость вверх `airVelocity`. Это и есть комба.
- Чем меньше `airHorizontal`, тем меньше цель улетает в сторону.
- Выше `maxComboHeight` блоков над землёй цель больше не поднимается, а зависает.
- Кулдаун атаки Java убран (`disableAttackCooldown`), каждый клик бьёт на полную силу, как в PE.
- Пауза между ударами по одной цели настраивается через `hitInvulnerabilityTicks`.
- Над хотбаром показывается счётчик «Комбо xN».

## Настройка
Файл `config/bedrockcombo.json` (после правки: `/combo reload`) или команды в игре:

    /combo                         — все настройки с описанием
    /combo set <опция> <значение>  — изменить (сохраняется сразу)
    /combo reload | /combo reset

Менять настройки можно с правами оператора. В одиночной игре права не нужны.

| Опция | По умолч. | Что делает |
|---|---|---|
| `enabled` | true | включить / выключить мод |
| `affectMobs` / `affectPlayers` | true | кого подбрасывать |
| `launchVelocity` | 0.50 | скорость вверх при ударе с земли |
| `airVelocity` | 0.40 | скорость вверх при ударе по цели в воздухе |
| `maxComboHeight` | 6.0 | потолок комбо в блоках над землёй (0 = нет) |
| `groundHorizontal` | 0.80 | отбрасывание в сторону на земле (1 = ваниль) |
| `airHorizontal` | 0.25 | отбрасывание в сторону в воздухе |
| `extraKnockbackMultiplier` | 0.50 | доп. отбрасывание от бега / Отбрасывания |
| `respectKnockbackResistance` | true | незеритовая броня, големы и т.п. сопротивляются подбросу |
| `disableAttackCooldown` | true | убрать кулдаун атаки |
| `hitInvulnerabilityTicks` | 20 | 20 = ваниль (удар раз в 10 тиков); 10 и меньше = бить каждым кликом |
| `showComboCounter` | true | счётчик комбо |
| `comboTimeoutTicks` | 40 | через сколько тиков без удара счётчик сбрасывается |

## Советы
- Выше и «воздушнее»: `launchVelocity 0.6`, `airVelocity 0.5`.
- Цель улетает от тебя: уменьши `airHorizontal` (даже до 0).
- Хочешь тапать быстрее: `hitInvulnerabilityTicks 10`.
- Друг в незеритовой броне не взлетает? Поставь `respectKnockbackResistance false`.
